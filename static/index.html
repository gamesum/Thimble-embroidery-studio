    Read a picture with AI (optional)

    Not set up yet

    Everything else in Thimble works without this. To let the AI turn your pictures into stitches, it needs a "key" - like a password - from Anthropic, the company that makes the Claude AI. It takes about 5 minutes, once.

    1. Open the Anthropic website and sign in, or make a free account with your email.
    2. Add a little money: click Billing (left side) and add credit - $5 is plenty to start. Each picture read costs a few cents.
    3. Click API keys, then the Create key button. Call it Thimble. If it asks which workspace, pick Default.
    4. Press Copy next to the new key (it starts with sk-ant-), come back here, click in the box below and paste it (Ctrl+V).
    5. Press Test my key, then Save.

    Saved only on this computer, in Thimble's own settings file. It's only ever sent to Anthropic, along with the pictures you choose to read.

    Advanced: workspace ID (only if Thimble asks for it)

    Only needed for a key that was made outside a workspace. Find it in the Anthropic website under Settings → Workspaces. Leave empty otherwise.
